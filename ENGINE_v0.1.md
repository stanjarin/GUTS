# GUTS ENGINE v0.1

Nine-book spectator reader shell with NoBo-derived performance state machine.

- READY → ARMED → PAID → CLEAN
- RESET → READY
- six-second dwell qualifies the selected force page
- selected chapter opener protected
- paid page persists
- force marker replacement uses `$$$`
- target instruction remains **first new paragraph**
- six new books load from `PRIMED/*_GUTS_PRIME2.json`
- three inherited finished books load unchanged from canonical NoBo NoFo raw masters pending physical repository copy
- hidden maintenance control: four taps at bottom-right

This is an engineering build. Visual Gutenberg camouflage is provisional; pairing/Cloudflare spectator-session transport is not yet implemented.
