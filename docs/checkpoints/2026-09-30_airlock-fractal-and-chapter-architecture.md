## Air-lock work — key insight
The original paragraph-level problem was reframed.

The hard problem is not merely wording. It is VOICE:
- Who is doing the talking?
- If a character/focal consciousness is present, memory/thought/association can work.
- If the prose is pure description or unseen narration, inventing a mind/voice can expose the graft.
- Separately, any air-lock that explicitly highlights a "word", "name", "letters", etc. risks pointing at the method.

Perelman draft was acceptable in principle because it frames the force as a memory, not explicitly as a word.

Peake draft exposed the problem more clearly because it tried to work even when no character was present.

## Fractal search
The thread explored whether one invariant operation could survive:
- first person
- close third
- omniscient narration
- dialogue
- pure description
- weather / architecture / empty scene

The rejected direction was local adaptation around each socket. That is antithetical to the desired fractal because it requires bespoke scene reading.

A stronger interim invariant was:
- use narration itself as the universal carrier;
- instantiate the payload briefly;
- erase its significance.

A minimal candidate emerged:
> For a moment there was this: $$$. Then it was gone.

This obeyed the brief but also suggested that the brief itself might be wrong.

## Breakthrough — CREATE THE CHAPTER
Stanley proposed: **"We create the chapter."**

This moved the deception up one architectural level.

Instead of forcing one alien air-lock paragraph to survive inside arbitrary genuine prose, create a plausible performance chapter whose Voice is controlled from the first line.

Design STANdards consequence:
- existing chapter boundaries are not sacred if they are an unnecessary constraint;
- reduce until further reduction would destroy function;
- solve at chapter scale, not by multiplying local prose exceptions.

## First-pass synthetic chapter architecture
Stanley's 1am sketch:
- every selectable chapter can present a bogus/performance chapter behind a legit front page that extends below the initial viewport;
- following pages can be performance pages with varied vertical positioning to defeat persistence-of-vision cues;
- once PAID, pages revert to real book except the paid page.

Ruthless review produced these cautions / refinements:
- Do NOT literally repeat the same page; recognition of prose is more dangerous than mere visual persistence.
- Prefer a short synthetic middle section per BOOK, with several genuinely different pages and staggered socket positions.
- A genuine opener or legit first page can establish trust before synthetic material.
- Once PAID, preserve enough neighbouring performance context to avoid a narrative cliff; then clean on departure.
- Potential stronger reduction: chapters need not be permanently bogus. A chapter can become the performance chapter only after selection/commitment, while others remain genuine.
- This suggests roughly one controlled mini-scene / synthetic section per book rather than hundreds of bespoke air-lock paragraphs.
